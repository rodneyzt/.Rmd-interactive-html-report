Tabsets

This interactive section demonstrates an tabset-driven document structure.

💡 How to Build Standard & Nested Tabsets

To create tabsets, follow this exact structure:

  1. Define the Parent Container: Create a high-level header (e.g., ## Header 2) and add {.tabset} right next to it.
  2. Add Tab Modifiers: You can stack styles together inside the curly braces. For example, {.tabset .tabset-pills .tabset-fade} creates pill-shaped buttons with a smooth fade-in transition effect.
  3. Build the Sub-Tabs: Every heading exactly one level down (e.g., ### Header 3) will automatically become a clickable tab inside that parent.
  4. Nest Multiple Levels: If you want tabs inside tabs, add {.tabset} to a sub-tab (e.g., ### Tab 2 {.tabset}), which turns the next heading layer down (#### Header 4) into internal child tabs.

💡 How to Build Collapsible Accordions

To create collapsible data blocks, follow this exact structure:

  1. Define the Accordion Container: Put the content you need to hide/reveal between <details> and </details> HTML tags.

  2. Link Group Names: Add a name="my-group" attribute to your <details> tags. Giving multiple accordions the same name ensures only one can be open at a time (opening one automatically closes the others).

  3. Set the Clickable Header: Put the title or name of the box between <summary> and </summary> tags so it remains visible at all times.

  4. Apply Custom Styling: Wrap your hidden text content within Pandoc fenced divs (::: accordion-content and :::) to pick up the padding and design rules from your custom.css file.
